# 鹤壁市外国语中学 · 高中部

一个纯静态的学校信息展示页，零依赖、零构建，可直接部署到 GitHub Pages。
视觉语言：宣纸 × 墨 × 校徽蓝 × 朱砂 × 银杏金；液体玻璃采用多层折射与流动高光实现。

## 目录结构

```
seniorhighschool/
├── index.html              单页，含 8 个章节
├── README.md
└── assets/
    ├── css/style.css       视觉系统（设计令牌 / 玻璃组件 / 响应式 / 降低动效）
    ├── js/main.js          交互（顶栏 / 抽屉 / 卷轴 / 入场 / 导航高亮 / 回顶）
    └── img/                影像素材，共 11 张，合计约 1.2 MB
```

## 本地预览

直接双击 `index.html` 即可（全部为相对路径，`file://` 下可正常工作）。

若需以 http 方式预览：

```bash
# 任选其一，在 seniorhighschool 目录下执行
python -m http.server 8080
npx serve .
```

然后访问 <http://localhost:8080>。

## 部署到 GitHub Pages

1. 新建仓库，将 `seniorhighschool` 内的全部文件放到仓库根目录（或 `docs/` 目录）。
2. 仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`。
3. 分支选 `main`，目录选 `/ (root)` 或 `/docs`，保存。
4. 稍候访问 `https://<用户名>.github.io/<仓库名>/`。

页面为相对路径引用，放在根目录或子目录均可正常显示。

## 交互与无障碍

- 4 个按钮均为真实行为：导航抽屉开合、影像卷轴左右翻页、返回顶部。
- 无空链接、无 `javascript:` 伪链接；站内锚点均指向真实存在的章节 `id`。
- 支持键盘操作：卷轴可用 ← → 浏览，`Esc` 关闭抽屉，全站可见焦点环。
- 遵循 `prefers-reduced-motion`，并保留打印样式。
- 脚本未执行时（`<noscript>` 场景）内容依然完整可读：入场动画的初始隐藏仅在 `html.js` 下生效。
