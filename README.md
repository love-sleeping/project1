# 鹤壁市外国语中学高中部网站

> 项目版本：`v2.5.0`  
> 更新日期：2026-10-24  
> 项目类型：静态网站（HTML / CSS / JavaScript）  
> 目标：用于展示学校相关介绍与校园文化的网页项目，可部署至 GitHub Pages 等静态网站托管服务。

## 项目简介

本项目是一个中文学校介绍网站。视觉方向以暖纸白、墨蓝、低饱和朱砂与古铜金为主，结合中文校园气质、清晰的编辑式排版与滚动章节体验。

网站包含学校介绍、校园相关内容、资料来源，以及“新的内容，由你书写。”独立章节和最后的制作人介绍页。项目基于已有的 `v2.4.1` 文件继续修改，尽量保留原有页面内容与交互，而非另建简化演示页面。

**注意：** 本项目目前尚未完成全部浏览器验收，也不代表学校官方发布或背书。学校事实、招生信息、照片来源及其使用权限，应在正式公开前逐项核实。

## 本地运行

### 方法一：直接打开

在文件管理器中双击 `index.html`，使用浏览器打开网站。

### 方法二：启动本地 HTTP 服务

在 Windows 下运行 `run-server.bat`。如果脚本无法启动，请检查电脑是否安装 Python，并确认终端能够运行 `python` 或 `py` 命令。

`start-local.bat` 主要用于直接打开页面；如遇到浏览器对本地文件或部分资源的限制，建议使用 HTTP 服务方式运行。

## 部署到 GitHub Pages

GitHub Pages 可以托管本项目这样的静态网站，不需要购买服务器。以下操作需要你登录自己的 GitHub 账号完成；本说明不会自动创建仓库或替你发布网站。

### 1. 创建 GitHub 仓库

1. 登录 [GitHub](https://github.com/)。
2. 点击右上角 `+`，选择 **New repository**。
3. 为仓库取一个名称，例如 `hebifl-fls-mingyun`。
4. 如果希望任何人都能访问网站，请将仓库设为 **Public**。公开仓库意味着其中的代码和文件也会公开。
5. 点击 **Create repository** 创建仓库。

### 2. 上传网站文件

将项目文件上传到仓库根目录。至少应包含：

- `index.html`
- `styles.css`
- `app.js`
- `image-sources.json`
- `VERSION.txt`
- `README.md`
- 其他页面实际引用的资源文件或目录

可以在 GitHub 仓库页面点击 **Add file → Upload files**，将这些文件拖入上传区域，然后填写提交说明并点击 **Commit changes**。

**重要：** 确保 `index.html` 位于仓库根目录，而不是多套一层项目文件夹。不要只上传 ZIP 文件；GitHub Pages 需要读取仓库中的网站文件。

### 3. 开启 GitHub Pages

1. 打开仓库的 **Settings**。
2. 在左侧找到 **Pages**。
3. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**。
4. 将分支选择为 `main`，目录选择 `/(root)`。
5. 点击 **Save**。
6. 等待 GitHub Pages 完成构建。部署状态和网站地址通常会显示在 Pages 设置页中。

如果你的默认分支不是 `main`，请改选实际存放网站文件的分支。

### 4. 访问网站

个人或组织项目站点通常使用以下形式的地址：

```text
https://<你的GitHub用户名>.github.io/<仓库名>/
```

例如，用户名和仓库名都需要替换成你实际创建的值。请以仓库 **Settings → Pages** 页面显示的地址为准；部署完成前该地址可能暂时无法访问。

### 5. 更新网站

以后修改网页时，将更新后的文件提交并推送到启用 Pages 的分支。GitHub Pages 会重新构建和发布。发布后如果浏览器仍显示旧页面，可尝试强制刷新或稍后再次访问。

## 已知限制与验收状态

- 当前项目未包含 `assets/photos/` 本地校园照片目录；校徽和部分校园照片仍引用外部资源，离线环境下可能无法加载。
- 外部图片或滚动库可能受到源站可用性、跨域策略或网络状况影响。
- 已进行的静态检查包括 ZIP 完整性检查、关键 HTML 章节检查及 JavaScript 语法检查；这些检查不等于完整的浏览器验收。
- 电脑端与手机端的视觉测试、所有交互的完整测试、远程图片逐项核查及学校信息的全面事实核验仍需完成。
- 本项目尚未通过本仓库实际部署至 GitHub Pages；只有在完成上传并按上述步骤启用 Pages 后，才能确认公网部署状态。
